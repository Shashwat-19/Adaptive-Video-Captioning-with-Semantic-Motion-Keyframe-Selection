# Lab 8: TF-IDF → PCA → K-Means / DBSCAN Clustering on MSVD Captions

This folder contains a **separate course lab assignment** (Lab 8) that applies
TF-IDF vectorization, PCA dimensionality reduction, and unsupervised clustering
(K-Means and DBSCAN) to captions from the MSVD (Microsoft Research Video
Description) dataset.

> **Note:** This lab is part of standalone coursework and is **unrelated** to the
> main video-captioning research pipeline found in `notebooks/`, `src/`,
> `configs/`, and the rest of this repository.
